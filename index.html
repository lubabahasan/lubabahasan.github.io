Project Details

Fruit Sorter

Stanford CIP Project

This web app was created for a Stanford Code In Place project. The goal was very simple: make a programme with all the python knowledge we had learned through that course. I took this chance to make a simple game in python named Fruit Sorter, where the player has to sort the fruits into the correct baskets using keyboard arrow keys.

For design elements I used my own pixel art components.

I kept the color palette a little fun with bright colors to make the game more engaging. The game is simple and fun to play, and it was a great way to practice my python skills.

Project Details

Fruit Basket

Wordpress Blog Website

Fruit Basket, created in 2022, is a personal side project where I explored new technologies to improve my web development skills.

This website functions as a digital journal, capturing my experiences and reflections while playing Genshin Impact. The design is inspired by the cozy, immersive world of the game, featuring a color palette dominated by soothing greens and accented with lively pops of color to bring pop of warmth and vibrancy.

Through this project, I was able to not only document my in-game journey but also to experiment with different web development tools, aiming to create a dynamic and engaging user experience.

Technologies Used:

Wordpress Responsive Design HTML5 CSS3
