This is my personal portfolio website, designed to showcase my projects, skills, and achievements. The website is built using HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: The layout adjusts for different screen sizes to ensure a seamless user experience.
- **Project Showcase**: A dedicated section highlighting my featured projects.
- **Contact Form**: Allows visitors to reach out to me directly.
- **Custom Styling**: Designed with unique CSS effects and custom SVG to create a visually engaging interface.

## Technologies Used

- **HTML5**: Structuring the content of the website.
- **CSS3**: Styling the elements with modern design techniques.
- **JavaScript**: Adding interactivity and animations.
